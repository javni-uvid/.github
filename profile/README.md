| [izborna-analiza](https://github.com/javni-uvid/izborna-analiza) · [izbornipodaci.rs](https://izbornipodaci.rs/) | Svaki fajl sa rezultatima koji RIK objavi, i svako biračko mesto provereno po istim pravilima |
| [osnova](https://github.com/javni-uvid/osnova) | Zajednička načela, pravila rada i bezbednost svih projekata |
