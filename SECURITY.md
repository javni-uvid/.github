# Bezbednost / Security

**Srpski.** Ako nađeš bezbednosni propust na nekom od sajtova organizacije javni-uvid ili u njihovom kodu, prijavi
ga privatno: kartica **Security** tog repozitorijuma → **Report a vulnerability**. Molimo te da ga ne objavljuješ
u javnom issue-u dok se ne ispravi. Odgovaramo u roku od nekoliko dana; projekte održava jedna osoba.

Pogrešan podatak na sajtu nije bezbednosni propust: za to otvori običan issue u repozitorijumu tog projekta.

**English.** If you find a security flaw in one of the javni-uvid sites or in their code, report it privately:
that repository's **Security** tab → **Report a vulnerability**. Please don't open a public issue before it is
fixed. Expect an answer within a few days; the projects have one maintainer.

A wrong fact on a site is not a security flaw: open an ordinary issue in that project's repository.

What every project guards and how:
[`shared/security.md`](https://github.com/javni-uvid/osnova/blob/main/shared/security.md) in javni-uvid/osnova.
